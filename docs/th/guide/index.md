# คู่มือผู้ใช้

> นี่คือฉบับแปลของ[หน้าภาษาอังกฤษ](../../guide/index.md) ซึ่งยังไม่ได้รับการตรวจทานโดยเจ้าของภาษา หากสองฉบับมีเนื้อหาต่างกัน ให้ถือหน้าภาษาอังกฤษเป็นหลัก

คู่มือนี้จัดเรียงตามคำถามที่ผู้ใช้มักถาม แต่ละหน้าเริ่มด้วยคำตอบโดยตรง
จากนั้นจึงให้โปรแกรมสั้น ๆ ที่รันได้ตามที่เขียนไว้ ผลลัพธ์ของโปรแกรม
การรับประกันที่อยู่เบื้องหลังคำตอบ และกรณีที่วิธีนั้นใช้ไม่ได้
ส่วน[บทเรียน (tutorials)](../../tutorials/ab-test.md) จะลงลึกในแต่ละหัวข้อมากกว่านี้

## ไลบรารีนี้ในหนึ่งย่อหน้า

**sequential-analysis** เป็นไลบรารี Python สำหรับการอนุมานเชิงสถิติ
กับข้อมูลที่เข้ามาทีละค่าสังเกต การทดสอบ ช่วงความเชื่อมั่น และตัวตรวจจับของไลบรารีสามารถดูผลได้หลังทุกค่าสังเกตและหยุดได้ทุกเมื่อ โดยอัตราความคลาดเคลื่อนยังคงเป็นไปตามที่กำหนด ไลบรารีนี้ครอบคลุม:

* SPRT ของ Wald และแผนแบบลำดับที่เหมาะสมที่สุด (optimal sequential plans)
* แผนแบบลำดับกลุ่ม (group sequential designs) สำหรับการทดลองทางคลินิก
  (การใช้จ่ายค่าแอลฟาแบบ O'Brien–Fleming และ Pocock, ขอบเขตความไร้ประโยชน์)
* การทดสอบ A/B ที่ใช้ได้ทุกขณะ (anytime-valid) ด้วยค่า e (e-values)
  และลำดับช่วงความเชื่อมั่น (confidence sequences)
* การตรวจจับจุดเปลี่ยน (change-point detection)
* ตัวกรอง Kalman ตัวกรองอนุภาค (particle filter) และตัวกรองแบบจำลองมาร์คอฟซ่อนเร้น (hidden Markov)
* การพยากรณ์และความผันผวนแบบ GARCH

ทุกการรันสามารถบันทึกเป็นจุดบันทึกสถานะ (checkpoint) ในรูป JSON
แล้วรันต่อใน Python ได้ตรงกันทุกบิต หรือรันต่อในตัวประมวลผล TypeScript โดยได้การตัดสินใจเหมือนกัน

## วิธีอ่านการรับประกัน

ทุกกระบวนการ (procedure) มีแอตทริบิวต์ `guarantee` คู่มือนี้อ้างถึงค่านี้ในทุกคำตอบ:

* **exact:** อัตราความคลาดเคลื่อนเป็นไปตามที่กำหนดที่ทุกขนาดตัวอย่างภายใต้ข้อสมมติที่ระบุไว้
* **asymptotic:** เป็นไปตามที่กำหนดโดยประมาณ และแม่นยำขึ้นเมื่อตัวอย่างใหญ่ขึ้น
* **model:** ความน่าจะเป็นถูกต้องแม่นตรงภายใต้แบบจำลองที่ระบุ
  แต่ไม่มีการอ้างใด ๆ นอกเหนือจากแบบจำลองนั้น
* **approximate:** เป็นค่าประมาณ แม้ภายใต้แบบจำลอง
* **none:** กระบวนการนี้เพียงแปลงข้อมูลและไม่ได้อ้างสิ่งใด
