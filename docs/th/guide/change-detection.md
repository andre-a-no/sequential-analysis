# จะตรวจจับการเปลี่ยนแปลงในสายข้อมูลการวัดได้อย่างไร?

> นี่คือฉบับแปลของ[หน้าภาษาอังกฤษ](../../guide/change-detection.md) ซึ่งยังไม่ได้รับการตรวจทานโดยเจ้าของภาษา หากสองฉบับมีเนื้อหาต่างกัน ให้ถือหน้าภาษาอังกฤษเป็นหลัก

**คำตอบสั้น ๆ** ให้ใช้ตัวตรวจจับจุดเปลี่ยนแบบออนไลน์ (online change-point detector) ซึ่งเฝ้าดูสายข้อมูลและส่งสัญญาณเตือนทันทีที่การแจกแจงดูเหมือนจะเปลี่ยนไป สัญญาณเตือนลวง (false alarm) ของมันถูกควบคุมด้วย**ความยาวรันเฉลี่ย** (average run length, ARL) คือจำนวนค่าสังเกตที่คาดหวังจนถึงสัญญาณเตือนลวงในขณะที่ไม่มีอะไรเปลี่ยนแปลง ใน sequential-analysis:

| สิ่งที่คุณรู้ก่อนการเปลี่ยนแปลง | กระบวนการ | การรับประกัน |
|---|---|---|
| การแจกแจงทั้งสอง (เช่น ปกติ ค่าเฉลี่ย 70 → 71) | `CUSUM`, `ShiryaevRoberts` | exact: ARL ≥ e^threshold |
| เฉพาะค่าเฉลี่ย และขอบเขตของค่า | `MeanEDetector` | exact สำหรับทุกการแจกแจงลักษณะนั้น |
| เฉพาะควอนไทล์ (เช่น เปอร์เซ็นไทล์ที่ 95 ของเวลาแฝง) | `QuantileEDetector` | exact สำหรับทุกการแจกแจง |
| แบบจำลองที่มีพารามิเตอร์ไม่ทราบค่า ทั้งก่อนและหลัง | `BayesianChangePoint` | ภายใต้แบบจำลองและการแจกแจงก่อน (prior) |

## เซนเซอร์ที่ค่าเฉลี่ยเลื่อนไป

เซนเซอร์อุณหภูมิอ่านค่าได้ 70.0 °C โดยมีสัญญาณรบกวนที่มีส่วนเบี่ยงเบนมาตรฐาน 0.5 ตั้งแต่ค่าที่อ่านลำดับที่ 600 เป็นต้นไป ค่าเฉลี่ยเป็น 70.4 CUSUM ที่มีค่าเกณฑ์ log(1000) ≈ 6.9 มี ARL อย่างน้อย 1,000 ค่าที่อ่าน:

```python
import math
import random

from sequential_analysis.procedures import CUSUM, Gaussian

rnd = random.Random(1)
readings = [rnd.gauss(70.0, 0.5) for _ in range(600)] + [rnd.gauss(70.4, 0.5) for _ in range(400)]

detector = CUSUM(Gaussian(sigma=0.5), theta0=70.0, theta1=70.4, threshold=math.log(1000))
state = detector.initial_state()
for t, x in enumerate(readings, start=1):
    state, out = detector.step(state, {"x": x})
    if out.alarm:
        print(f"alarm at reading {t}, {t - 600} readings after the shift")
        break
```

```text
alarm at reading 615, 15 readings after the shift
```

การเลื่อนที่น้อยกว่าหนึ่งส่วนเบี่ยงเบนมาตรฐานมองไม่เห็นด้วยตาเปล่าในค่าที่อ่านค่าใดค่าหนึ่ง CUSUM สะสมหลักฐานและพบการเลื่อนนั้น

## เมื่อค่าที่อ่านไม่ได้แจกแจงแบบปกติ

ARL ของ CUSUM เป็นจริงเฉพาะเมื่อค่าที่อ่านเป็นไปตามการแจกแจงที่คุณกำหนดให้ สำหรับข้อมูลที่เบ้ (แอมพลิจูดการสั่นสะเทือน เวลาแฝง ความยาวคิว) มันจะส่งสัญญาณเตือนลวงบ่อยกว่าที่วางแผนไว้มาก ตัวตรวจจับแบบ e (e-detectors) ต้องการข้อมูลน้อยกว่ามาก:

* `MeanEDetector` ต้องการค่าเฉลี่ยก่อนการเปลี่ยนแปลงและขอบเขตของค่า
* `QuantileEDetector` ต้องการเพียงควอนไทล์ก่อนการเปลี่ยนแปลง

ARL ของทั้งสองมีค่าอย่างน้อยเท่ากับเป้าหมายสำหรับ**ทุก**การแจกแจงที่มีค่าเฉลี่ยหรือควอนไทล์นั้น:

```python
from sequential_analysis.procedures import QuantileEDetector

rnd = random.Random(2)
vibration = [rnd.lognormvariate(0.0, 0.8) for _ in range(800)] + [rnd.lognormvariate(0.5, 0.8) for _ in range(400)]
q95 = math.exp(0.8 * 1.6449)          # the 95th percentile before the change
p95 = QuantileEDetector(q0=q95, p=0.95, arl=1000, direction="increase", statistic="cusum")
state = p95.initial_state()
for t, x in enumerate(vibration, start=1):
    state, out = p95.step(state, {"x": x})
    if out.alarm:
        print(f"the 95th percentile rose: alarm at reading {t}, {t - 800} readings after the change")
        break
```

```text
the 95th percentile rose: alarm at reading 887, 87 readings after the change
```

ในทางปฏิบัติ ควอนไทล์ก่อนการเปลี่ยนแปลงจะประมาณจากช่วงเวลาที่ระบบสงบ การรับประกันจึงเป็นจริงโดยประมาณ และยิ่งช่วงนั้นยาวก็ยิ่งแม่นยำ

## การเลือก ARL

ARL เป็นการแลกเปลี่ยนระหว่างสัญญาณเตือนลวงกับความล่าช้า หากอ่านค่านาทีละครั้ง ARL 1,000 ค่าที่อ่านหมายถึงสัญญาณเตือนลวงราวทุก 17 ชั่วโมงของการทำงานปกติต่อเซนเซอร์หนึ่งตัว เมื่อมีเซนเซอร์ 50 ตัวจะเป็นราว 70 ครั้งต่อวัน ให้เลือก ARL จากจำนวนสัญญาณเตือนลวงต่อวันที่คุณรับได้จากเซนเซอร์ทั้งหมดรวมกัน ในที่นี้ ARL 1,000,000 ค่าที่อ่านจะลดสัญญาณเตือนลวงของเซนเซอร์ 50 ตัวลงเหลือราวหนึ่งครั้งทุกสองสัปดาห์ ต้นทุนของสิ่งนี้น้อยกว่าที่คิด เพราะความล่าช้าในการตรวจจับเพิ่มขึ้นเพียงตามลอการิทึมของ ARL สำหรับ CUSUM ค่าเกณฑ์เปลี่ยนจาก 6.9 เป็น 13.8 และความล่าช้าเพิ่มขึ้นราวสองเท่า

ตัวตรวจจับเหล่านี้เป็นเครื่องมือติดตาม ไม่ใช่ระบบความปลอดภัย อย่าใช้แทนระบบเครื่องมือวัดเพื่อความปลอดภัย (safety instrumented system) ที่ได้รับการรับรอง
