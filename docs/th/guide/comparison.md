# เทียบกับไลบรารีอื่นแล้วเป็นอย่างไร?

> นี่คือฉบับแปลของ[หน้าภาษาอังกฤษ](../../guide/comparison.md) ซึ่งยังไม่ได้รับการตรวจทานโดยเจ้าของภาษา หากสองฉบับมีเนื้อหาต่างกัน ให้ถือหน้าภาษาอังกฤษเป็นหลัก

**คำตอบสั้น ๆ** ไลบรารีส่วนใหญ่ครอบคลุมวิธีตระกูลเดียวได้ดี sequential-analysis รวมวิธีตระกูลหลักของการอนุมานแบบลำดับไว้ภายใต้อินเทอร์เฟซเดียว:

* SPRT และแผนที่เหมาะสมที่สุด
* แผนแบบลำดับกลุ่ม (group sequential designs)
* การทดสอบที่ใช้ได้ทุกขณะ (anytime-valid) และลำดับช่วงความเชื่อมั่น (confidence sequences)
* การตรวจจับการเปลี่ยนแปลง (change detection)
* ตัวกรองแบบปริภูมิสถานะ (state-space filters)

สิ่งที่ไลบรารีเพิ่มเติมนอกเหนือจากตัววิธีเอง:

* ทุกกระบวนการระบุการรับประกันของตน (`exact`, `asymptotic`, `model`, ...)
* ทุกการรันบันทึกเป็นจุดบันทึกสถานะ (checkpoint) และรันต่อได้ตรงกันทุกบิต
* รูปแบบข้อมูลมีข้อกำหนดชัดเจนและถูกรันโดยการพัฒนาชุดที่สองใน TypeScript
* ไม่มีไลบรารีที่ต้องติดตั้งเพิ่ม

หากคุณต้องการเพียงวิธีเดียวจากรายการด้านล่างและใช้ไลบรารีที่เชี่ยวชาญด้านนั้นอยู่แล้ว ก็ใช้ไลบรารีนั้นต่อไป ตารางบอกว่าเครื่องมือแต่ละตัวเป็นทางเลือกโดยธรรมชาติในกรณีใด คำอธิบายเป็นจุดประสงค์หลักของแต่ละไลบรารี ณ เดือนตุลาคม 2026 และไม่ใช่รายการความสามารถทั้งหมด

| ความต้องการ | ทางเลือกโดยธรรมชาติ | สิ่งที่ sequential-analysis มีให้ |
|---|---|---|
| การทดสอบแบบขนาดตัวอย่างคงที่ การถดถอย อำนาจการทดสอบ | scipy.stats, statsmodels | ไม่ใช่จุดประสงค์ของไลบรารีนี้ |
| แผนแบบลำดับกลุ่มสำหรับการยื่นต่อหน่วยงานกำกับดูแล | rpact, gsDesign (R) | แผนแบบเดียวกัน ตรวจสอบเทียบกับ rpact ในชุดทดสอบ ดำเนินการทดลองทีละขั้นพร้อมจุดบันทึกสถานะ |
| ลำดับช่วงความเชื่อมั่น ค่า e | confseq (Python), safestats (R) | ลำดับช่วงความเชื่อมั่นสำหรับค่าเฉลี่ย ควอนไทล์ สัมประสิทธิ์การถดถอย ขนาดผลแบบสองตัวอย่าง; e-BH และ e-LOND สำหรับการทดสอบจำนวนมาก |
| การทดสอบ A/B ในรูปแพลตฟอร์มที่มี UI | GrowthBook, Statsig, Eppo, Optimizely (แพลตฟอร์ม) | เอนจินสำหรับฝังในระบบ: การทดสอบแบบแม่นตรงสำหรับอัตราคอนเวอร์ชัน ตัวชี้วัดที่มีขอบเขตและตัวชี้วัดแบบอัตรา SRM และ FDR เมื่อมีหลายตัวชี้วัด |
| การแบ่งช่วงตามจุดเปลี่ยนแบบออฟไลน์ของอนุกรมที่สิ้นสุดแล้ว | ruptures (Python), changepoint (R) | การตรวจจับแบบออนไลน์ขณะที่ข้อมูลเข้ามา: CUSUM, Shiryaev–Roberts, ตัวตรวจจับแบบ e, จุดเปลี่ยนแบบเบย์ออนไลน์ |
| ตัวกรอง Kalman | filterpy, statsmodels state space | ตัวกรอง Kalman, Kalman แบบทนทาน, ตัวกรองอนุภาค และตัวกรอง HMM พร้อมการปรับให้เรียบ (smoothing) และจุดบันทึกสถานะ |
| GARCH | arch | GARCH(1,1) และ GJR ที่ปรับให้ได้ค่าสูงสุดเดียวกับ arch (ตรวจสอบในชุดทดสอบ) แล้วรันแบบออนไลน์ |
| แบบจำลองมาร์คอฟซ่อนเร้น | hmmlearn | ตัวกรองแบบออนไลน์ Baum–Welch ที่ให้ผลตรงกับ hmmlearn และ EM แบบออนไลน์ |
| การพยากรณ์ | statsmodels และอื่น ๆ | การพยากรณ์แบบ ETS และ AR ที่ตรงกับ statsmodels เรียนรู้แบบออนไลน์ พร้อมช่วงแบบคอนฟอร์มัล (conformal intervals) |

## กรณีที่เครื่องมืออื่นดีกว่า

* **การยื่นต่อหน่วยงานกำกับดูแล** rpact ถูกใช้อย่างแพร่หลายเพื่อจุดประสงค์นี้ และผู้พัฒนามีเอกสารการตรวจสอบความถูกต้อง (validation documentation) ให้ sequential-analysis ให้ผลตรงกับ rpact สำหรับแผนที่ครอบคลุม แต่ผู้สนับสนุนการวิจัย (sponsor) ก็ยังต้องตรวจสอบความถูกต้องของไลบรารีนี้เอง
* **การวิเคราะห์ออฟไลน์ขนาดใหญ่บนอาร์เรย์** ไลบรารีที่ใช้ numpy เร็วกว่าเมื่อคิดต่อค่าสังเกต sequential-analysis ถูกสร้างมาสำหรับข้อมูลทีละค่าสังเกต ดู[ความเร็ว](../../performance.md)สำหรับต้นทุนของแต่ละกระบวนการ
* **วิธีที่ไลบรารียังไม่มี** ยังไม่มีการทดสอบมัธยฐานแบบสองตัวอย่าง ไม่มีกระบวนการ Hawkes หลายตัวแปร และไม่มีแบบจำลอง ARIMA ที่มีพจน์ค่าเฉลี่ยเคลื่อนที่ (moving average) ดู[บันทึกการเปลี่ยนแปลง (changelog)](../../changelog.md)สำหรับสิ่งที่ถูกเพิ่มเข้ามา
