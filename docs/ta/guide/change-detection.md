# அளவீடுகளின் தொடரோட்டத்தில் ஏற்படும் மாற்றத்தைக் கண்டறிவது எப்படி?

> இது [ஆங்கிலப் பக்கத்தின்](../../guide/change-detection.md) மொழிபெயர்ப்பு. தமிழைத் தாய்மொழியாகக் கொண்ட ஒருவர் இதை இன்னும் மதிப்பாய்வு செய்யவில்லை; இரண்டுக்கும் இடையே வேறுபாடு இருந்தால், ஆங்கிலப் பக்கமே அதிகாரப்பூர்வமானது.

**சுருக்கமான பதில்.** இணையவழி மாற்றப் புள்ளி கண்டறிவியைப் (online change-point
detector) பயன்படுத்துங்கள். அது தொடரோட்டத்தைக் கண்காணித்து, பரவல் மாறியதாகத்
தோன்றியவுடன் எச்சரிக்கை (alarm) எழுப்புகிறது. அதன் தவறான எச்சரிக்கைகள் (false
alarms) **சராசரி ஓட்ட நீளத்தால்** (average run length, ARL) கட்டுப்படுத்தப்படுகின்றன:
எதுவும் மாறாதபோது ஒரு தவறான எச்சரிக்கை வரை எதிர்பார்க்கப்படும் கவனிப்புகளின்
எண்ணிக்கை. sequential-analysis-இல்:

| மாற்றத்துக்கு முன் உங்களுக்குத் தெரிந்தது | செயல்முறை | உத்தரவாதம் |
|---|---|---|
| இரண்டு பரவல்களும் (எ.கா. இயல்நிலை (normal), சராசரி 70 → 71) | `CUSUM`, `ShiryaevRoberts` | exact: ARL ≥ e^threshold |
| சராசரி மட்டும், மதிப்புகளின் வரம்புகளும் | `MeanEDetector` | அத்தகைய ஒவ்வொரு பரவலுக்கும் exact |
| ஒரு கணுமம் (quantile) மட்டும் (எ.கா. தாமதத்தின் 95-ஆவது சதமானம் (percentile)) | `QuantileEDetector` | ஒவ்வொரு பரவலுக்கும் exact |
| மாற்றத்துக்கு முன்னும் பின்னும் அறியப்படாத அளவுருக்களுடன் (parameters) ஒரு மாதிரியுரு | `BayesianChangePoint` | மாதிரியுரு மற்றும் முன் பரவலின் (prior) கீழ் |

## சராசரி நகரும் ஓர் உணரி

ஒரு வெப்பநிலை உணரி 0.5 திட்ட விலக்கம் (standard deviation) கொண்ட இரைச்சலுடன்
70.0 °C காட்டுகிறது. 600-ஆவது அளவீட்டிலிருந்து சராசரி 70.4 ஆகிறது. log(1000) ≈ 6.9
வாயில் மதிப்பு (threshold) கொண்ட CUSUM-இன் ARL குறைந்தது 1,000 அளவீடுகள்:

```python
import math
import random

from sequential_analysis.procedures import CUSUM, Gaussian

rnd = random.Random(1)
readings = [rnd.gauss(70.0, 0.5) for _ in range(600)] + [rnd.gauss(70.4, 0.5) for _ in range(400)]

detector = CUSUM(Gaussian(sigma=0.5), theta0=70.0, theta1=70.4, threshold=math.log(1000))
state = detector.initial_state()
for t, x in enumerate(readings, start=1):
    state, out = detector.step(state, {"x": x})
    if out.alarm:
        print(f"alarm at reading {t}, {t - 600} readings after the shift")
        break
```

```text
alarm at reading 615, 15 readings after the shift
```

ஒரு திட்ட விலக்கத்தைவிடக் குறைவான நகர்வு எந்தவொரு தனி அளவீட்டிலும் கண்ணுக்குத்
தெரியாது. CUSUM சான்றுகளைத் திரட்டி அதைக் கண்டுபிடிக்கிறது.

## அளவீடுகள் இயல்நிலைப் பரவலில் இல்லாதபோது

நீங்கள் வழங்கிய பரவல்களை அளவீடுகள் பின்பற்றினால் மட்டுமே CUSUM-இன் ARL நிலைக்கிறது.
சாய்வான (skewed) தரவுக்கு (அதிர்வு வீச்சுகள், தாமதங்கள், வரிசை நீளங்கள்) அது
திட்டமிட்டதைவிட மிக அடிக்கடி தவறான எச்சரிக்கைகளை எழுப்புகிறது. e-கண்டறிவிகளுக்கு
(e-detectors) மிகக் குறைவே தேவை:

* `MeanEDetector`-க்கு மாற்றத்துக்கு முந்தைய சராசரியும் மதிப்புகளின் வரம்புகளும்
  தேவை.
* `QuantileEDetector`-க்கு மாற்றத்துக்கு முந்தைய ஒரு கணுமம் மட்டுமே தேவை.

அந்தச் சராசரி அல்லது கணுமம் கொண்ட **ஒவ்வொரு** பரவலுக்கும் அவற்றின் ARL குறைந்தது
இலக்கு அளவாவது இருக்கும்:

```python
from sequential_analysis.procedures import QuantileEDetector

rnd = random.Random(2)
vibration = [rnd.lognormvariate(0.0, 0.8) for _ in range(800)] + [rnd.lognormvariate(0.5, 0.8) for _ in range(400)]
q95 = math.exp(0.8 * 1.6449)          # the 95th percentile before the change
p95 = QuantileEDetector(q0=q95, p=0.95, arl=1000, direction="increase", statistic="cusum")
state = p95.initial_state()
for t, x in enumerate(vibration, start=1):
    state, out = p95.step(state, {"x": x})
    if out.alarm:
        print(f"the 95th percentile rose: alarm at reading {t}, {t - 800} readings after the change")
        break
```

```text
the 95th percentile rose: alarm at reading 887, 87 readings after the change
```

நடைமுறையில், மாற்றத்துக்கு முந்தைய கணுமம் ஓர் அமைதியான காலத்திலிருந்து
மதிப்பிடப்படுகிறது. அப்போது உத்தரவாதம் தோராயமாக நிலைக்கிறது; அந்தக் காலம் எவ்வளவு
நீளமோ அவ்வளவு சிறப்பாக.

## ARL-ஐத் தேர்ந்தெடுத்தல்

ARL தவறான எச்சரிக்கைகளையும் தாமதத்தையும் சமன்செய்கிறது. நிமிடத்துக்கு ஓர் அளவீடு
என்றால், 1,000 அளவீடுகள் கொண்ட ARL என்பது இயல்பான இயக்கத்தில் ஓர் உணரிக்குச்
சுமார் 17 மணி நேரத்துக்கு ஒரு தவறான எச்சரிக்கை. 50 உணரிகள் இருந்தால் அது ஒரு
நாளைக்குச் சுமார் 70. எல்லா உணரிகளையும் சேர்த்து ஒரு நாளைக்கு எத்தனை தவறான
எச்சரிக்கைகளை நீங்கள் தாங்க முடியும் என்பதிலிருந்து ARL-ஐத் தேர்ந்தெடுங்கள்:
இங்கே, 1,000,000 அளவீடுகள் கொண்ட ARL 50 உணரிகளையும் சுமார் இரண்டு வாரங்களுக்கு
ஒரு தவறான எச்சரிக்கை என்ற அளவுக்குக் குறைக்கிறது. இதன் விலை தோன்றுவதைவிடக்
குறைவு, ஏனெனில் கண்டறிதல் தாமதம் ARL-இன் மடக்கையுடன் (logarithm) மட்டுமே
வளர்கிறது. CUSUM-க்கு வாயில் மதிப்பு 6.9-இலிருந்து 13.8 ஆகிறது, தாமதம் ஏறத்தாழ
இரட்டிப்பாகிறது.

இந்தக் கண்டறிவிகள் கண்காணிப்புக் கருவிகள், பாதுகாப்பு அமைப்புகள் அல்ல.
சான்றளிக்கப்பட்ட பாதுகாப்புக் கருவிமய அமைப்புக்குப் (safety instrumented system)
பதிலாக அவற்றைப் பயன்படுத்தாதீர்கள்.
