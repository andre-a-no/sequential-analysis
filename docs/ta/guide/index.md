# பயனர் வழிகாட்டி

> இது [ஆங்கிலப் பக்கத்தின்](../../guide/index.md) மொழிபெயர்ப்பு. தமிழைத் தாய்மொழியாகக் கொண்ட ஒருவர் இதை இன்னும் மதிப்பாய்வு செய்யவில்லை; இரண்டுக்கும் இடையே வேறுபாடு இருந்தால், ஆங்கிலப் பக்கமே அதிகாரப்பூர்வமானது.

இந்த வழிகாட்டி மக்கள் கேட்கும் கேள்விகளின்படி ஒழுங்கமைக்கப்பட்டுள்ளது. ஒவ்வொரு
பக்கமும் ஒரு நேரடிப் பதிலுடன் தொடங்குகிறது. பின்னர் எழுதியபடியே இயங்கும் ஒரு
சிறிய நிரல், அதன் வெளியீடு, பதிலின் பின்னாலுள்ள உத்தரவாதம், அந்த முறை
பொருந்தாத சூழ்நிலைகள் ஆகியவை தரப்படுகின்றன. [பயிற்சிகள்](../../tutorials/ab-test.md)
ஒவ்வொரு தலைப்பையும் மேலும் ஆழமாக விளக்குகின்றன.

## ஒரே பத்தியில் நூலகம்

**sequential-analysis** என்பது ஒரு நேரத்தில் ஒரு கவனிப்பாக (observation) வந்து
சேரும் தரவின் மீது புள்ளியியல் அனுமானம் (statistical inference) செய்வதற்கான
Python நூலகம். அதன் சோதனைகள், நம்பக இடைவெளிகள் (confidence intervals) மற்றும்
கண்டறிவிகள் (detectors) ஒவ்வொரு கவனிப்புக்குப் பிறகும் பார்க்கப்படலாம், எந்தக்
கணத்திலும் நிறுத்தப்படலாம்; அப்போதும் அவற்றின் பிழை விகிதங்கள் (error rates)
நிலைக்கின்றன. இது உள்ளடக்குவன:

* Wald-இன் SPRT மற்றும் உகந்த தொடர்முறைத் திட்டங்கள் (optimal sequential plans);
* மருத்துவ ஆய்வுகளுக்கான குழுத் தொடர்முறை வடிவமைப்புகள் (group sequential designs)
  (O'Brien–Fleming மற்றும் Pocock செலவிடல், பயனின்மை எல்லைகள் (futility bounds));
* e-மதிப்புகள் (e-values) மற்றும் நம்பகத் தொடர்கள் (confidence sequences) கொண்ட
  எப்போதும்-செல்லுபடியான (anytime-valid) A/B சோதனைகள்;
* மாற்றப் புள்ளி கண்டறிதல் (change-point detection);
* Kalman, துகள் (particle) மற்றும் மறை Markov (hidden Markov) வடிகட்டிகள்;
* முன்கணிப்பு (forecasting) மற்றும் GARCH ஏற்ற இறக்கம் (volatility).

ஒவ்வொரு ஓட்டத்தையும் (run) JSON சோதனைப்புள்ளியாக (checkpoint) சேமித்து, Python-இல்
பிட்டுக்குப் பிட் அப்படியே மீண்டும் தொடரலாம், அல்லது அதன் TypeScript
இயக்கியில் (executor) அதே முடிவுகளுடன் தொடரலாம்.

## உத்தரவாதங்களை எப்படிப் படிப்பது

ஒவ்வொரு செயல்முறைக்கும் (procedure) ஒரு `guarantee` பண்புக்கூறு உண்டு. வழிகாட்டி
ஒவ்வொரு பதிலுடனும் அதைக் குறிப்பிடுகிறது:

* **exact:** குறிப்பிட்ட அனுமானங்களின் கீழ் ஒவ்வொரு மாதிரி அளவிலும் (sample size)
  பிழை விகிதம் நிலைக்கிறது.
* **asymptotic:** அது தோராயமாக நிலைக்கிறது, பெரிய மாதிரிகளுக்கு மேலும் சிறப்பாக.
* **model:** குறிப்பிட்ட மாதிரியுருவின் (model) கீழ் நிகழ்தகவுகள் துல்லியமானவை,
  ஆனால் அதற்கு அப்பால் எதுவும் கோரப்படவில்லை.
* **approximate:** மாதிரியுருவின் கீழும்கூட ஒரு தோராயம் மட்டுமே.
* **none:** செயல்முறை தரவை உருமாற்றுகிறது, எந்தக் கோரிக்கையும் செய்வதில்லை.
