# Глоссарий

> Это перевод [страницы на английском языке](../../guide/glossary.md). Перевод ещё не проверен носителем языка; если тексты расходятся, верной считается английская страница.

Термины, используемые в последовательном анализе и в этой библиотеке.
Распространённые синонимы приведены в скобках.

**Последовательный анализ** (sequential analysis; sequential testing,
sequential inference — последовательная проверка гипотез, последовательный
вывод). Статистика, в которой число наблюдений не фиксируется заранее.
После каждого наблюдения или группы наблюдений процедура решает,
остановиться или продолжить. Основан Вальдом (Wald 1945).

**Подглядывание** (peeking; optional stopping, data peeking, continuous
monitoring — произвольная остановка, непрерывный мониторинг). Многократный
просмотр критерия с фиксированным объёмом выборки с остановкой, когда он
значим. Увеличивает долю ложноположительных результатов; см.
[подглядывание](peeking.md).

**SPRT** (sequential probability ratio test — последовательный критерий
отношения вероятностей, критерий Вальда). Накапливает логарифм отношения
правдоподобия двух простых гипотез и останавливается, когда тот выходит за
пределы интервала. `SPRT`; усечённые варианты `TwoSPRT` (2-SPRT Лордена,
Lorden) и `kiefer_weiss_plan`. См. [SPRT](sprt.md).

**Групповой последовательный дизайн** (group sequential design; interim
analyses, group sequential trial — промежуточные анализы, групповое
последовательное исследование). Несколько запланированных анализов, у
каждого своя граница. Границы выбираются так, чтобы общая ошибка первого
рода равнялась alpha. `group_sequential_design`. См.
[клинические исследования](clinical-trials.md).

**Функция расходования альфы** (alpha spending function; error spending,
Lan–DeMets — расходование ошибки). Определяет, какую часть ошибки первого
рода можно израсходовать к каждой доле информации. Расходование типа
O'Brien–Fleming тратит вначале мало, расходование типа Pocock — равномерно.
`spending="obrien-fleming"`, `"pocock"`, ...

**Доля информации** (information fraction). Часть запланированной
статистической информации (пациентов, событий), достигнутая к моменту
анализа.

**Граница бесперспективности** (futility boundary; non-binding futility —
необязывающая граница бесперспективности). Нижняя граница: ниже неё
рекомендуется остановка из-за отсутствия эффекта. Необязывающую границу
можно игнорировать, не увеличивая ошибку первого рода.

**Вывод, валидный в любой момент** (anytime-valid inference; always-valid
inference, safe anytime-valid inference, SAVI). Критерии и интервалы,
гарантии которых выполняются одновременно при всех объёмах выборки, так что
за ними можно следить непрерывно и останавливать их по любой причине.

**E-значение** (e-value; e-variable, betting score — e-переменная, оценка
ставки). Неотрицательная статистика, математическое ожидание которой при
нулевой гипотезе не больше 1. Большое e-значение свидетельствует против
нулевой гипотезы: отклонение при превышении 1/alpha даёт ошибку первого рода
не больше alpha. Выход `log_e_value` многих процедур.

**E-процесс** (e-process; test martingale, test supermartingale, wealth
process — тестовый мартингал, тестовый супермартингал, процесс капитала).
Последовательность e-значений, остающаяся валидной в моменты остановки. Её
текущий максимум при нулевой гипотезе пересекает 1/alpha с вероятностью не
больше alpha (неравенство Вилля, Ville's inequality).

**Всегда валидное p-значение** (always-valid p-value; anytime-valid
p-value, sequential p-value — последовательное p-значение). P-значение,
валидное в любой момент остановки. Оно обратно текущему максимуму
e-процесса. Выход `p_value` процедур, валидных в любой момент.

**Доверительная последовательность** (confidence sequence; anytime-valid
confidence interval, always-valid confidence interval, time-uniform
confidence interval — доверительный интервал, валидный в любой момент,
равномерный по времени доверительный интервал). Последовательность
интервалов, которая с вероятностью не менее 1 − alpha содержит истинное
значение одновременно при всех объёмах выборки.
`BettingConfidenceSequence`, `QuantileConfidenceSequence`,
`CatoniConfidenceSequence`, `AsymptoticConfidenceSequence`, а также выходы
`lower` и `upper` многих критериев. См.
[доверительные последовательности](confidence-sequences.md).

**mSPRT** (mixture SPRT, Robbins' mixture — смешанный SPRT, смесь
Роббинса). SPRT, альтернатива которого усредняется по априорному
распределению, что делает его валидным в любой момент против любой
альтернативы. `NormalMixtureSPRT` (известная дисперсия), `TMixtureSPRT`
(неизвестная дисперсия).

**Проверка гипотез через ставки** (testing by betting). Построение
e-процессов как капитала игрока, который делает ставки против нулевой
гипотезы. `BettingMeanTest`, `BettingConfidenceSequence`,
`KernelTwoSampleTest`.

**GROW** (growth-rate optimal — оптимальный по скорости роста).
E-значение, выбранное так, чтобы максимизировать ожидаемый логарифмический
рост свидетельств при альтернативе. `TwoProportionTest(method="grow")`.

**Универсальный вывод** (universal inference). E-значение из отношения
правдоподобия, в котором альтернатива оценивается только по прошлым
данным. Остаётся валидным при адаптивных дизайнах.
`TwoProportionTest(method="universal")`.

**e-BH** (e-Benjamini–Hochberg). Контролирует долю ложных открытий (false
discovery rate) по множеству e-значений при любой зависимости.
`MultipleTests`, `e_bh`.

**e-LOND, онлайн-FDR** (online FDR). Контроль доли ложных открытий для
серии гипотез, решения по которым принимаются по одной. `OnlineFDR`.

**SRM** (sample ratio mismatch — несоответствие соотношения выборок).
Наблюдаемое распределение трафика между группами отличается от
настроенного — признак ошибки в эксперименте. `SampleRatioMismatch`.

**CUPED** (controlled experiments using pre-experiment data, covariate
adjustment, regression adjustment — поправка на ковариату, регрессионная
поправка). Уменьшает дисперсию эффекта в A/B-тесте с помощью ковариаты,
измеренной до эксперимента. `ABTest(covariate=True)`,
`AnytimeLinearModel`.

**Метрика-отношение** (ratio metric; delta method — дельта-метод).
Метрика, представляющая собой отношение двух сумм по пользователю,
например выручка на сессию. `RatioABTest`.

**Обнаружение разладки** (change-point detection; change detection,
quickest detection, online anomaly detection — обнаружение изменений,
скорейшее обнаружение, онлайн-обнаружение аномалий). Подача сигнала тревоги
вскоре после изменения распределения потока. `CUSUM`, `ShiryaevRoberts`,
`MeanEDetector`, `QuantileEDetector`, `BayesianChangePoint`. См.
[обнаружение изменений](change-detection.md).

**ARL** (average run length, ARL₀, mean time to false alarm — средняя
длина серии, среднее время до ложной тревоги). Ожидаемое число наблюдений
до ложной тревоги, когда ничего не изменилось. Способ контроля ложных
тревог у детекторов разладки.

**E-детектор** (e-detector). Детектор разладки, построенный из
e-процессов, по одному на каждый возможный момент изменения. Его ARL
гарантирован при непараметрической нулевой гипотезе. `MeanEDetector`,
`QuantileEDetector`.

**Задача Кифера–Вейсса** (Kiefer–Weiss problem). Поиск последовательного
критерия с максимальным объёмом выборки, минимизирующего наибольший
ожидаемый объём выборки. `kiefer_weiss_plan`.

**Оперативная характеристика** (operating characteristic). Вероятности
ошибок и распределение объёма выборки плана как функции истинного
параметра. `operating_characteristic`.

**Контрольная точка** (checkpoint). Значение JSON, с которого запуск
продолжается точно. `Run.checkpoint`, `Run.restore`. См.
[потоковую обработку](streaming.md).

**Дайджест истории** (history digest). Хеш-цепочка SHA-256 по
наблюдениям, которые использовал запуск, хранящаяся в каждой контрольной
точке для аудита.

**Гарантия** (guarantee; `exact`, `asymptotic`, `model`, `approximate`,
`none`). Атрибут, в котором каждая процедура этой библиотеки заявляет, что
она обещает. См. [Какой метод выбрать?](../../choosing.md).
