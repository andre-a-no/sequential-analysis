# Руководство пользователя

> Это перевод [страницы на английском языке](../../guide/index.md). Перевод ещё не проверен носителем языка; если тексты расходятся, верной считается английская страница.

Руководство построено вокруг вопросов, которые задают пользователи. Каждая
страница начинается с прямого ответа, затем приводит короткую программу,
которая работает в том виде, как написана, её вывод, гарантию, на которой
основан ответ, и случаи, когда метод неприменим. В
[учебных материалах](../../tutorials/ab-test.md) каждая тема разобрана подробнее.

## Библиотека в одном абзаце

**sequential-analysis** — библиотека Python для статистического вывода по
данным, которые поступают по одному наблюдению. Её критерии, доверительные
интервалы и детекторы можно просматривать после каждого наблюдения и
останавливать в любой момент, и при этом их вероятности ошибок сохраняются.
Она охватывает:

* последовательный критерий отношения вероятностей Вальда (SPRT) и
  оптимальные последовательные планы;
* групповые последовательные дизайны (group sequential designs) для
  клинических исследований (функции расходования альфы O'Brien–Fleming и
  Pocock, границы бесперспективности);
* A/B-тесты, валидные в любой момент (anytime-valid), с e-значениями и
  доверительными последовательностями;
* обнаружение разладки (change-point detection);
* фильтры Калмана, частичные фильтры и фильтры скрытых марковских моделей;
* прогнозирование и модели волатильности GARCH.

Состояние любого запуска можно сохранить в контрольную точку в формате JSON
и продолжить бит в бит в Python или в исполнителе на TypeScript с теми же
решениями.

## Как читать гарантии

У каждой процедуры есть атрибут `guarantee`. Руководство приводит его
вместе с каждым ответом:

* **exact:** вероятность ошибки соблюдается при любом объёме выборки при
  сформулированных допущениях.
* **asymptotic:** соблюдается приближённо, и тем точнее, чем больше выборка.
* **model:** вероятности точны в рамках заявленной модели, но за её
  пределами ничего не утверждается.
* **approximate:** приближение даже в рамках модели.
* **none:** процедура преобразует данные и ничего не гарантирует.
