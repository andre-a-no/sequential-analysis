# دليل المستخدم

> هذه ترجمة [للصفحة الإنجليزية](../../guide/index.md). لم يراجعها متحدث أصلي باللغة بعد؛ وحيثما اختلفت الصفحتان، فالصفحة الإنجليزية هي المرجع المعتمد.

نُظِّم هذا الدليل حول الأسئلة التي يطرحها الناس. تبدأ كل صفحة بإجابة
مباشرة، ثم تقدّم برنامجًا قصيرًا يعمل كما هو مكتوب، ومخرجاته، والضمان
الذي تستند إليه الإجابة، والحالات التي لا تنطبق فيها الطريقة. أما
[الدروس التعليمية](../../tutorials/ab-test.md) فتتعمّق أكثر في كل موضوع.

## المكتبة في فقرة واحدة

**sequential-analysis** مكتبة Python للاستدلال الإحصائي على بيانات تصل
مشاهدةً تلو الأخرى. يمكن النظر في اختباراتها وفترات الثقة فيها وكواشفها
بعد كل مشاهدة وإيقافها في أي لحظة، وتبقى معدلات الخطأ فيها صحيحة. وهي
تغطي:

* اختبار نسبة الاحتمال التتابعي لوالد (SPRT) والخطط التتابعية المثلى؛
* التصاميم التتابعية الجماعية (group sequential designs) للتجارب
  السريرية (إنفاق ألفا من نوع O'Brien–Fleming ونوع Pocock، وحدود عدم
  الجدوى)؛
* اختبارات A/B الصالحة في أي وقت باستخدام قيم e (e-values) ومتتاليات
  الثقة (confidence sequences)؛
* كشف نقاط التغيّر (change-point detection)؛
* مرشحات كالمان (Kalman) والجسيمات (particle) وماركوف المخفي (hidden
  Markov)؛
* التنبؤ وتقلّب GARCH.

يمكن حفظ كل تشغيل في نقطة حفظ (checkpoint) بصيغة JSON واستئنافه في
Python مطابقًا بتًّا ببت، أو متابعته في المنفّذ المكتوب بلغة TypeScript
مع القرارات نفسها.

## كيف تُقرأ الضمانات

لكل إجراء سمة `guarantee`. ويذكرها الدليل مع كل إجابة:

* **exact (دقيق):** معدل الخطأ صحيح عند كل حجم عينة في ظل الافتراضات
  المذكورة.
* **asymptotic (تقاربي):** صحيح تقريبًا، ويتحسّن مع العينات الأكبر.
* **model (نموذجي):** الاحتمالات دقيقة في ظل النموذج المذكور، ولا يُدّعى
  شيء خارجه.
* **approximate (تقريبي):** تقريب حتى في ظل النموذج.
* **none (لا شيء):** الإجراء يحوّل البيانات ولا يقدّم أي ادعاء.
