# sequential-analysis 0.4.0: API reference for AI assistants

> Python library for sequential statistical inference: tests, confidence sequences and detectors that may be checked after every observation and stopped at any time with their error guarantees intact (SPRT, group sequential designs, anytime-valid A/B tests, change detection, Kalman/particle/HMM filters, forecasting, GARCH).

This file is generated from the code of version 0.4.0 by tools/make_llms_api.py. The constructors, guarantees, input names and output fields below are the library's own; when writing code, use them rather than names recalled from other libraries. The user guide with worked examples is at https://andre-a-no.github.io/sequential-analysis/guide/, and llms.txt at https://andre-a-no.github.io/sequential-analysis/llms.txt lists the documentation.

## How the library is used

- Install `pip install sequential-analysis`; import `sequential_analysis`. Python 3.8 or later, no required dependencies (`pip install "sequential-analysis[fast]"` adds numpy for the array-heavy procedures).
- Procedures are in `sequential_analysis.procedures`. Each is a pure transition: `state = proc.initial_state()`, then for each observation `state, out = proc.step(state, x)`, where `x` is a dict keyed by the procedure's input names (listed below; most default to `"x"`, A/B tests to `"arm"` and `"y"`). There is no `fit`/`predict` or array API on procedures: feed observations one at a time, in order.
- `out` is a frozen dataclass with the output fields listed below. Tests report `out.decision`: None while undecided, then `"reject_h0"` or `"accept_h0"` (`procedures.REJECT_H0`, `procedures.ACCEPT_H0`). Change detectors report `out.alarm`. Many tests also give `p_value` (anytime-valid), `log_e_value` and `lower`/`upper` (a confidence sequence).
- `alpha` is the error rate of the whole run, however often it is looked at; it is not spent per look.
- For streams use `Run(proc, topology=..., delivery=..., consumers=[...])` and `run_sync(run, observations)`, where each observation is `Observation(input_name, value, seq=..., key=..., source=...)`. A topology relates inputs: `KeyJoin(("arm", "y"))` joins an assignment and an outcome by `key`. `run.state` is the current state, `Recorder()` as a consumer collects the outputs.
- `run.checkpoint()` is a JSON value; `Run.restore(proc, checkpoint)` continues the run bit for bit and refuses a checkpoint of another procedure, configuration or version (`IncompatibleCheckpoint`).
- Each procedure states its promise in `proc.guarantee`:
  - `exact`: error rates, coverage or false-alarm rates hold at every sample size, under the stated assumptions
  - `asymptotic`: they hold approximately, the better the larger the sample
  - `model`: exact probabilities under the stated model and prior; no error rate beyond the model
  - `approximate`: an approximation even under the model (Monte Carlo, variational, stochastic approximation)
  - `none`: a transformation of the data; no inferential claim
  Prefer an exact procedure where one answers the question.

## Which procedure for which question

- Conversion rate A vs B, looked at any time: `TwoProportionTest`. Bounded metric (capped revenue, a share): `BoundedABTest`. Events per unit of exposure: `RateRatioTest`. Ratio metric (revenue per session): `RatioABTest`. Mean with a pre-experiment covariate (CUPED): `ABTest(covariate=True)`. Traffic split: `SampleRatioMismatch`. Several metrics or arms: `MultipleTests` (e-BH). A series of experiments: `OnlineFDR`.
- A few planned interim analyses (clinical trials): `group_sequential_design(...)`, then `GroupSequentialTest`, `GroupSequentialTwoMeans`, `GroupSequentialProportions` or `GroupSequentialLogRank` built with `.from_design(design, n_max)` (for the log-rank test, the number of events instead of `n_max`); any statistic: `GroupSequentialMonitor`.
- Simple hypothesis against simple hypothesis, fewest observations: `SPRT(family, theta0, theta1, alpha, beta)`; with a maximum sample size `TwoSPRT` or `kiefer_weiss_plan` + `PlanTest`. Families: `Gaussian(sigma)`, `Bernoulli()`, `Poisson()`, `Exponential()`.
- Mean, anytime-valid: normal with known variance `NormalMixtureSPRT`, unknown variance `TMixtureSPRT`, bounded data `BettingMeanTest` / `BettingConfidenceSequence`, a bound on the standard deviation `CatoniConfidenceSequence`, long runs of anything `AsymptoticConfidenceSequence`. Median or any quantile: `QuantileTest`, `QuantileConfidenceSequence`. Are two groups distributed alike: `KernelTwoSampleTest`. Regression coefficients: `AnytimeLinearModel`. Survival: `AnytimeLogRankTest`.
- Change detection: `CUSUM`, `ShiryaevRoberts` (known distributions), `MeanEDetector`, `QuantileEDetector` (nonparametric), `BayesianChangePoint`.
- Filtering: `KalmanFilter`, `LocalLevelKalman`, `RobustKalmanFilter`, `HiddenMarkovFilter`, `OnlineHMM`, `ParticleFilter`, `BootstrapParticleFilter`.
- Forecasting: `ExponentialSmoothing`, `AutoRegressive`, `PoissonSmoothing`, `ModelAveraging`, `ConformalForecast`, `ForecastComparison`; several series `VectorAutoRegressive`, `CrossCorrelation`, `DynamicRegression`; events `HawkesProcess`, `EventStudy`; volatility `GARCH` (fit with `fit_garch`).
- Not in the library: a two-sample test of medians, multivariate Hawkes processes, ARIMA with moving-average terms.

## Procedures (sequential_analysis.procedures)

Import each with `from sequential_analysis.procedures import <Name>`.

### ABTest

`ABTest(allocation: 'float' = 0.5, alpha: 'float' = 0.05, *, covariate: 'bool' = False, arms: 'tuple[int, int]' = (1, 0), start: 'int' = 1000, tuned_for: 'float' = 1000.0, stop_on_reject: 'bool' = False, arm_input: 'str' = 'arm', input: 'str' = 'y', covariate_input: 'str' = 'x')`

- Guarantee: asymptotic.
- Anytime-valid confidence sequence for a difference of means, with covariate adjustment.
- Inputs: `arm`, `x`, `y`.
- Output fields: `n: int`, `means: tuple[float | None, float | None]`, `estimate: float`, `lower: float | None`, `upper: float | None`, `variance_ratio: float | None`, `decision: str | None`.

- Guarantee: exact.
- Anytime-valid F-test (t-test for d = 1) and confidence sequence for regression coefficients.

- Output fields: `n: int`, `estimates: tuple[float, ...] | None`, `f: float | None`, `log_e_value: float`, `p_value: float`, `lower: float | None`, `upper: float | None`, `decision: str | None`.

### CUSUM

`CUSUM(family: 'Family', theta0: 'float', theta1: 'float', threshold: 'float', input: 'str' = 'x')`

- Guarantee: exact.
- W_n = max(0, W_{n-1} + log f_theta1(X_n)/f_theta0(X_n)); alarm when W_n >= threshold.
- Inputs: `x`.
- Output fields: `n: int`, `statistic: float`, `alarm: bool`.

## sequential_analysis.procedures: families, models and helpers

- `Bernoulli(*args, **kwargs)`: Binary observations with unknown success probability.
- `BetaBernoulliModel(a: 'float' = 1.0, b: 'float' = 1.0)`: 0/1 data with unknown success probability ~ Beta(a, b).
- `CategoricalEmission(probabilities)`: y in {0, ..., M-1} with `P(y = s | z = k) = probabilities[k][s]`.
- `Exponential(*args, **kwargs)`: Non-negative durations with unknown rate (mean 1/rate).
- `Family(*args, **kwargs)`: What the likelihood-ratio procedures need from a one-parameter family.
- `Gaussian(sigma: 'float' = 1.0)`: Normal observations with unknown mean and known standard deviation.
- `GaussianEmission(means, sds)`: y | z = k ~ N(means[k], sds[k]^2).
- `LinearGaussianModel(phi: 'float', q: 'float', r: 'float', m0: 'float' = 0.0, p0: 'float' = 1.0)`: z_t = phi z_{t-1} + N(0, q), y_t = z_t + N(0, r), z_0 ~ N(m0, p0).
- `MultivariateGaussianEmission(means, covariances)`: y | z = k ~ N_d(means[k], covariances[k]), for a vector observation y of length d.
- `NormalGammaModel(mu0: 'float' = 0.0, kappa0: 'float' = 1.0, alpha0: 'float' = 1.0, beta0: 'float' = 1.0)`: Normal data with unknown mean and precision: mean | tau ~ N(mu0, 1/(kappa0 tau)), tau ~ Gamma(alpha0, beta0).
- `Poisson(*args, **kwargs)`: Counts with unknown rate.
- `PoissonEmission(rates)`: y | z = k ~ Poisson(rates[k]).
- `PoissonGammaModel(shape: 'float' = 1.0, rate: 'float' = 1.0)`: Counts with unknown rate: rate ~ Gamma(shape, rate).
- `StateSpaceModel(*args, **kwargs)`: What ParticleFilter needs from a model. States are floats (dimension 1) or tuples of floats.
- `StochasticVolatilityModel(mu: 'float', phi: 'float', sigma: 'float')`: Log-variance h_t = mu + phi (h_{t-1} - mu) + sigma eta_t; return y_t = exp(h_t / 2) eps_t.
- `StudentTEmission(means, scales, df)`: y | z = k ~ means[k] + scales[k] T(df[k]): location-scale Student t, robust to outliers.
- `StudentTLocalLevel(q: 'float', scale: 'float', df: 'float', m0: 'float' = 0.0, p0: 'float' = 1.0)`: z_t = z_{t-1} + N(0, q), y_t = z_t + scale * t_df, z_0 ~ N(m0, p0): a level observed with outliers.
- `averaged_counts(*, discounts: 'Sequence[float]' = (0.5, 0.7, 0.8, 0.9, 0.95, 0.98, 0.995, 1.0), exposure: 'str | None' = None, forgetting: 'float' = 1.0, horizon: 'int' = 1, coverage: 'float' = 0.9, input: 'str' = 'y') -> 'ModelAveraging'`: Count forecasts that learn how fast the rate moves: model averaging over a grid of discounts.
- `averaged_smoothing(*, trend: 'str | None' = None, period: 'int | None' = None, alphas: 'Sequence[float]' = (0.05, 0.1, 0.2, 0.3, 0.5, 0.7, 0.9), betas: 'Sequence[float]' = (0.01, 0.1, 0.3), gammas: 'Sequence[float]' = (0.01, 0.1, 0.3), phis: 'Sequence[float]' = (0.9, 0.98), regressors: 'Sequence[str]' = (), transform: 'str | None' = None, forgetting: 'float' = 1.0, horizon: 'int' = 1, coverage: 'float' = 0.9, input: 'str' = 'y') -> 'ModelAveraging'`: Exponential smoothing that learns its smoothing parameters: model averaging over a grid.
- `e_bh(log_e_values: 'Sequence[float]', alpha: 'float') -> 'list[int]'`: Indices rejected by the e-BH procedure at level alpha, from log e-values.
- `emission_from_spec(spec) -> 'CategoricalEmission | GaussianEmission | PoissonEmission | MultivariateGaussianEmission | StudentTEmission'`: The emission model whose `spec()` is `spec` (mirrors emissionFromSpec of the TypeScript executor).
- `kiefer_weiss_point(family: 'Family', theta0: 'float', theta1: 'float', a0: 'float', a1: 'float') -> 'float'`: Intermediate point at which both boundaries are reached at the same rate.
